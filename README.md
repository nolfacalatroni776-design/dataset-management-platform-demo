# 数据集管理平台交互 Demo

设计评审与交互体验用示例，包含数据集管理、数据浏览、语义画布、预标注、本体管理、难例挖掘、导入和存储管理。

最新修订：2026-11-03。搜索框提供关键词、语义、以媒体。查找相似直接从数据编号、字段单元格或媒体卡片发起，原查询区展示“相似于”条件；字段入口使用对应单字段索引，编号入口使用配置的字段组合并展示参与字段。Top K、方向、最低相似度与排除参考选项即时更新原列表。缺少索引时保留参考，预填字段及兼容模型构建索引，采用后继续查询。以媒体支持直接粘贴、预览与替换图片。保存视图保留参考 ID、字段、索引和参数。数据质量、重复检测、数据聚类以平铺操作打开；生成任务从运行记录查看。语义画布独立生成二维投影。版本支持创建、发布和下拉切换；已移除版本对比。概览最近 3 条和完整操作记录共用日志，范围选择、字段排序及分布即时筛选继续保留。

示例使用模拟数据，模型调用、向量与异步任务在浏览器内模拟。打开页面即可体验，右上角“页面定位”可跳转交互场景，“重置演示”恢复初始示例。

本仓库通过 GitHub Pages 发布单文件交互 Demo。
