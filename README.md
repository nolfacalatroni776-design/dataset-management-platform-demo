# 数据集管理平台 Demo

在线地址：https://nolfacalatroni776-design.github.io/dataset-management-platform-demo/

平台提供可复用预标注方案、独立运行、方案版本和本地保存。用户在数据列表选择数据，复用方案或创建配置，通过已有模型服务执行预标注并查看结果。

## 预标注方案与运行

数据浏览一次只定位一个具体子集，不提供“全部子集”。不同子集可以有不同的字段、类型和资源格式，字段筛选、统计、画廊及语义画布只读取当前子集的定义。进入浏览时默认定位当前版本的默认子集和全部划分；切换子集清除旧查询与临时选择，重新定位全部划分。旧链接中的 subset=all 或不可用子集回到当前版本的默认子集与全部划分，不合并字段和数据；旧跨子集视图不自动套用。

- 在数据列表勾选同一子集的数据后点击“模型预标注”。没有方案时直接配置；已有方案时选择“使用方案”或“新建配置”。配置弹窗始终提供“选择已有方案”；平台方案核对本次名单后点击“执行 N 条预标注”，直接创建并排队运行，无需再次启动。本次名单只读展示，调整数据需返回列表。
- 数据列表的“预标注记录”展示独立运行。每条记录可查看运行和统计；统计基于记录固定输入。数据集不设独立“预标注”页签。
- 新建配置在最后“试运行与提交”选择“同时保存为新方案”并填写名称，点击提交时保存；不勾选则以临时配置提交。配置、取消和样本试运行不保存方案。历史临时运行也可点击“将本次配置保存为方案”。保存字段及顺序、模型、输出、本体映射和执行默认值；当次数据、结果、Token 与授权不保存到方案。
- 已有方案修改后，在提交时默认保存新版本，也可另存为新方案；旧运行保留原版本和配置快照。保存失败阻止本次提交或推理；继续和重试不重复创建版本。列表保留搜索，支持复制、版本记录及可恢复归档；已归档方案直接在列表中恢复。
- 方案按数据集保存在当前站点的浏览器 localStorage，支持刷新复用；连接、任务及结果仍是页面会话状态，HF 刷新后需重新连接，不支持跨设备或团队同步。
- 详细设计：[预标注方案与运行](preannotation-schemes-design.md)。
- 模型选择与资源边界：[模型调用与计算资源边界](model-execution-boundaries.md)。

## 使用

1. 在数据浏览中选择同一子集的数据，点击“模型预标注”。可直接新建配置，或通过“选择已有方案”复用配置；已有平台方案核对本次名单后即可执行。
2. 配置输入、输出定义/本体后，直接选择已有模型；模型列表包含平台内置模型和用户实际添加的 API 模型，按任务展示兼容项。每个模型绑定版本与调用地址。缺少模型时点击“添加自定义推理 API”，填写接口协议、名称、地址、授权范围、凭证、模型版本及适用任务，保存后自动选中；API 连接无需配置服务所在区域。平台内置及通用自定义 API 为模拟执行。
3. 使用“Hugging Face”时，在窗口或集成管理中配置自己的 HF Access Token。Token 需要 Make calls to Inference Providers 权限、可用额度，以及模型要求的授权。不要将 Token 发到聊天中。
4. 选择任务，在统一输入区选择一个或多个字段。文本/JSON 任务可调整顺序和组合格式；图文任务将图片作为真实 PNG 附件发送。目标检测可多选图片字段，同一条数据中的每张图分别调用模型，结果关联各自图片。
5. 目标检测选择已发布的图像矩形框本体，确认模型类别到本体标签的映射，并设置未映射类别策略。文本分类选择本体和目标分类问题，候选类别取自该问题的选项。
6. 选择模型和服务商，确认允许发送所选字段。HF 可先试运行 1 条，再点击执行剩余数据，并在提交时选择保存方案；只有一条数据且试运行已完成时，点击“提交本次运行”，沿用结果且不重复调用。一条双图记录会分别处理两张图。查看逐图片字段的检测框、原始类别/本体标签、文本、原始响应、耗时及任务统计，导出 JSON。

支持图片目标检测（hf-inference）、图像描述、文本摘要/自定义指令、翻译、文本分类和 JSON 信息抽取；模型与服务商按 HF 实时返回的可用性检查。每批最多 50 条，默认并发 1，可在高级设置调整至 1–8；单次请求超时默认 90 秒，可设 1–600 秒。失败项手动重试。401/402/403/429 会停止新请求派发，并保留并发中已返回的结果。

道路集包含 screenshot 和 screenshot_right 两个图片字段，使用不同的 demo SVG 插图，调用前转换为实际 PNG 内容。可选择图片字段并上传本地图片用于本次任务，替换范围限定到该记录的该字段；原始数据保持不变。

## 声音与视频事件识别

- 声音事件识别：识别音频里出现了哪种声音及其起止时间，例如“警报声，00:12–00:16”。语音转写则输出说话的文字内容。
- 视频事件识别：识别某段视频发生了哪种动作或事件及其起止时间，例如“跌倒，00:08–00:11”。视频目标检测则输出各帧对象及检测框。
- 两类事件均选择时间轴区间本体，返回事件标签、开始/结束时间及模型实际提供的置信度。可识别类别由模型决定，本体负责统一标注定义。
- 当前 Demo 两类事件使用模拟执行，音频示例为“说话、背景噪声”，视频示例为“操作演示、页面切换”；HF 尚未接入音视频事件推理，上述警报/跌倒仅用于解释任务含义。

## 高级执行设置与任务详情

- 向量构建与语义画布在任务内加载模型，提供默认收起的“任务计算资源”：资源池、CPU/GPU 实例规格、实例数量、处理并发和任务超时。向量索引和检索统一使用平台默认服务，任务与集成管理不提供检索服务选择或添加。计算资源与索引服务独立。
- 所有预标注模型均按已部署的服务调用，包括平台内置、自定义 API 与 HF；“请求设置”只提供并发、单次请求超时。模型服务的部署资源不在每次预标注中配置。
- 提交时固定配置快照；任务详情记录排队/开始/结束时间、每次尝试、处理数量、错误与可获取的用量。重试保留原配置和历史记录。
- 目标检测同时展示数据条数和图片字段次数，例如 100 条 × 2 个图片字段 = 200 字段次。请求并发限制同时生效于全部图片字段；单次请求只发送一张图，重试仅处理失败或结构异常的字段，继续运行仅处理未完成字段。
- 平台资源池和调度为明确标注的演示，可体验资源不足、恢复后重新排队、取消排队、执行超时重试；向量失败重试保留已有产物，画布失败仅重试二维坐标。
- HF 并发与超时实际影响请求。展示浏览器测量的任务/请求耗时与本地等待，累计服务商返回的 Tokens 并显示用量覆盖。服务商未提供的内部排队、GPU 用量不推算，费用以账户账单为准。
- 手动停止中止浏览器等待并保留可继续的输入；服务商可能仍在处理已发出的请求。
- 并发、超时、额度、限流和手动停止的成功及异常路径使用明确标记的接口契约响应验证；有效账户的付费推理尚未验收。
- 详细设计：[计算资源与任务执行](resource-execution-design.md)。

## 字段说明

预标注结果状态统一显示“成功”或“失败”。调用正常完成且输出符合任务定义时为成功，正常返回空内容或未检测到目标同样计入成功；请求、资源读取、模型执行或输出结构校验出错时为失败，具体原因保留在结果说明中。尚未执行的数据单独显示“未处理”。状态筛选和成功/失败数量按同一口径合并，空输出可通过对象数、输出内容及说明查看。

右上角“设计说明”默认开启。语义画布、预标注配置、记录和结果的标签可悬停或聚焦查看用途、信息来源、计数口径与操作影响，Esc 收起。完整字段定义见[语义画布与预标注字段说明](workflow-field-help.md)。

## 本体与组合输入

- 预标注入口在没有方案时直接打开配置，已有方案时提供选择方案或新建配置；配置弹窗始终保留“选择已有方案”入口。配置中直接选择模型；API 协议在添加连接时配置，复用方案自动载入其模型和接口绑定，平台方案在执行确认后直接排队运行。
- 类别映射不提供逐项确认按钮。平台配置点击“下一步”统一确认全部映射；HF 单页配置在试运行或提交执行时统一确认。HF 检测从模型公开 config.json 读取原始类别，暂不可读时可手动添加。至少采用一个有效类别，属性取值须完整；新增本体标签不会改变模型识别能力。
- 检测结果固定本体发布版本、定义快照和映射，同时保留模型原始类别、坐标及响应。未映射类别默认显示失败，原因为输出结构校验未通过；也可明确选择不采用并记录忽略数量。
- 文本分类按所选本体问题生成单选/多选输出要求，返回结果绑定问题、选项和本体版本 ID；超出选项范围或单选返回多个类别时显示失败，并保留具体校验原因。
- 文本/JSON 任务支持同一条记录多个文本、JSON、数值、布尔及时间字段组合；图像描述支持图片字段与文字上下文组合，具体模型对图片数量的限制以服务响应为准。
- 目标检测可多选图片字段，共用模型、本体、类别映射和阈值，每张图独立处理。HF 适配器将所选字段拆成单图请求；检测框、尺寸、状态和原始响应均关联对应图片字段。专用分割、转写、OCR 等接口仍使用单个资源字段；实体识别可明确文本跨度定位字段。
- 多字段顺序、组合格式和字段类型固定在任务中。目标检测的一个图片字段缺失或无效时只记录该字段失败，其他图片继续处理；成功字段保留，全部选中字段成功后该条才计为成功覆盖。组合输入任务的必需字段缺失或类型无效时，该条失败且不发送推理请求；0 和 false 是有效值。
- 难例挖掘复用目标检测运行时，可选择该运行中的图片字段；只读取该字段的有效预测，其他图片的检测框不参与本次评价。

## 运行边界

- GitHub Pages 是静态页面，直接请求 Hugging Face 官方接口。Token 只保存在当前页面 JavaScript 内存中，不进入 localStorage、sessionStorage、任务或导出文件。
- 预标注方案保存在浏览器 localStorage；连接、任务和结果保存在页面会话中，刷新会重置；请在刷新前导出需要保留的结果。
- HF 身份验证与推理权限验证分开：保存连接确认账户身份，模型权限、额度和区域限制由实际试运行检查。
- Hub revision 仅记录选择时的仓库状态，托管服务实际运行版本以服务商返回信息为准。
- 平台服务预标注、其他集成、质量扫描和向量等流程使用示例数据并标明模拟执行；HF 路径直接请求真实服务，不回退到模拟结果。
- 验证覆盖真实模型信息读取、无效 Token 的真实 401 响应，以及明确标记的接口契约响应。配置存储与双图推理契约各 14 项通过，双图契约不发起真实网络请求。本体映射、组合输入、图文附件、双图片字段选择/结果/失败重试、任务导出、异常策略、停止及移动端交互按各自验证记录验收；生产平台模型服务和有效 HF 账户的成功推理尚未验收。

## 在线模型列表与费用（2026-11-13 核查）

“模型预标注 → 浏览模型”读取 HF 当前在线服务，支持模型名搜索、服务商筛选、输出单价排序及仅显示 HF 标记免费的服务。

- 聊天及图文模型目录：https://router.huggingface.co/v1/models 。模型与服务商的价格单位为 USD / 百万 Tokens；仅 is_free=true 的服务被视为临时免费。缺失价格不等于免费。
- 目标检测目录使用 HF Hub 在线推理筛选；当前适配 hf-inference 的 object-detection 协议，至多读取 100 个候选。按计算时长计费，目录未提供具体单价。
- 读取公开列表不需要 Token，不发起推理请求。2026-11-13 实测：2 个目标检测模型、132 个聊天模型，其中 52 个支持图片输入；未发现明确标记免费的服务。
- 2026-11-13 核查的官方定价为：免费账户没有自动赠送的月度推理额度；PRO 每月包含 $2 计算额度，Team / Enterprise 为每席位 $2。免费账户需购买额度，或使用服务商实际提供的临时优惠。
- 官方规则：https://huggingface.co/docs/inference-providers/en/pricing ；模型目录及价格字段说明：https://huggingface.co/docs/inference-providers/en/hub-api 。实际可用性、价格与优惠可能变化，请按最新接口和账户账单确认。

## 导入数据

第一步“选择目标”确认草稿版本、子集和划分。数据来源提供本地文件、对象存储和 Hugging Face；向量索引与检索由平台默认服务管理。
