# 数据集管理平台交互 Demo

设计评审与交互体验用示例，包含数据集管理、数据浏览、语义画布、预标注、本体管理、版本对比、难例挖掘、导入和存储管理。

最新修订：2026-11-03。数据浏览统一搜索：关键词、语义、以样本和以媒体共用搜索框、字段条件与原结果表；可组合条件、保存完整查询视图、按相似度排序和批量操作。向量索引完成后可直接检索，二维投影在语义画布独立生成；数据策展提供质量扫描、聚类与独特性、重复组及保留项、分析记录。概览最近 3 条与完整操作记录共用同一日志；范围下拉、字段排序、分布即时筛选及前期修订继续保留。

示例使用模拟数据，模型调用、向量与异步任务在浏览器内模拟。打开页面即可体验，使用右上角“页面定位”跳转到各交互场景；“重置演示”恢复初始示例。

本仓库通过 GitHub Pages 发布单文件交互 Demo。
