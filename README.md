# 数据集管理平台 Demo

在线地址：https://nolfacalatroni776-design.github.io/dataset-management-platform-demo/

2026-11-16 更新：参照 Voxel51 的 Agents / Runs 结构，新增可复用预标注方案、独立运行、方案版本与本地保存；保留双来源、本体、多字段和高级执行设置。

## 预标注方案与运行

- 数据集进入“预标注”，查看“预标注方案 / 运行记录”；在数据列表勾选新数据后点击“模型预标注”，可直接选择已有方案新运行。
- 配置可保存为方案，历史运行也可点击“将本次配置保存为方案”。保存字段及顺序、模型、输出、本体映射和执行默认值；当次数据、结果、Token 与授权不保存到方案。
- 修改后保存新版本，旧运行保留原版本和配置快照。列表保留搜索，支持复制、版本记录及可恢复归档；已归档方案直接在列表中恢复。
- 方案按数据集保存在当前站点的浏览器 localStorage，支持刷新复用；连接、任务及结果仍是页面会话状态，HF 刷新后需重新连接，不支持跨设备或团队同步。
- 详细设计：[预标注方案与运行](preannotation-schemes-design.md)。

## 使用

1. 在数据浏览中选择同一子集的数据，点击“模型预标注”，选择已有方案或“创建方案”，再选择预标注来源。
2. “平台已集成模型服务”保留原四步流程：输入、输出定义/本体、服务与模型、样本试运行与提交。可选择平台内置服务、客服模型服务、视觉推理服务等已登记连接。此分支仍为模拟执行。
3. 使用“Hugging Face”时，在窗口或集成管理中配置自己的 HF Access Token。Token 需要 Make calls to Inference Providers 权限、可用额度，以及模型要求的授权。不要将 Token 发到聊天中。
4. 选择任务，在统一输入区选择一个或多个字段，调整顺序，选择按字段名分段或 JSON 对象组合。右侧预览实际组合的数据；图文任务将图片作为真实 PNG 附件发送。
5. 目标检测选择已发布的图像矩形框本体，确认模型类别到本体标签的映射，并设置未映射类别策略。文本分类选择本体和目标分类问题，候选类别取自该问题的选项。
6. 选择模型和服务商，确认允许发送所选字段。先试运行 1 条，再执行剩余数据；查看检测框、原始类别/本体标签、文本、原始响应、耗时及任务统计，导出 JSON。

支持图片目标检测（hf-inference）、图像描述、文本摘要/自定义指令、翻译、文本分类和 JSON 信息抽取；模型与服务商按 HF 实时返回的可用性检查。每批最多 50 条，默认并发 1，可在高级设置调整至 1–8；单次请求超时默认 90 秒，可设 1–600 秒。失败项手动重试。401/402/403/429 会停止新请求派发，并保留并发中已返回的结果。

道路集原有样本是 demo SVG 插图；调用前转换为实际 PNG 内容。可在窗口中上传本地图片用于本次任务，原始数据保持不变。

## 高级执行设置与任务详情

- 向量构建、语义画布和平台内置预标注提供默认收起的高级设置：资源池、CPU/GPU 实例规格、实例数量、处理并发和任务超时。向量存储/检索连接与计算资源独立。
- 托管模型服务与 HF 提供请求并发、单次请求超时；计算资源由已配置服务托管。
- 提交时固定配置快照；任务详情记录排队/开始/结束时间、每次尝试、处理数量、错误与可获取的用量。重试保留原配置和历史记录。
- 平台资源池和调度为明确标注的演示，可体验资源不足、恢复后重新排队、取消排队、执行超时重试；向量失败重试保留已有产物，画布失败仅重试二维坐标。
- HF 并发与超时实际影响请求。展示浏览器测量的任务/请求耗时与本地等待，累计服务商返回的 Tokens 并显示用量覆盖。服务商未提供的内部排队、GPU 用量不推算，费用以账户账单为准。
- 手动停止中止浏览器等待并保留可继续的输入；服务商可能仍在处理已发出的请求。
- 本轮验证使用明确标记的接口契约响应覆盖并发、超时、额度、限流和手动停止；没有使用有效账户额度完成付费推理。
- 详细设计：[计算资源与任务执行设计补充](resource-execution-design.md)。

## 本体与组合输入

- 预标注入口先显示方案库；新建配置默认使用平台服务，两种来源可直接切换，复用方案按其来源载入。
- HF 检测从模型公开 config.json 读取原始类别；配置暂不可读时可手动添加类别。建议映射需逐项确认，不会因新增本体标签而改变模型识别能力。
- 检测结果固定本体发布版本、定义快照和映射，同时保留模型原始类别、坐标及响应。未映射类别默认标为结构异常；也可明确选择不采用并记录忽略数量。
- 文本分类按所选本体问题生成单选/多选输出要求，返回结果绑定问题、选项和本体版本 ID；超出选项范围或单选返回多个类别时标为结构异常。
- 文本/JSON 任务支持同一条记录多个文本、JSON、数值、布尔及时间字段组合；图像描述支持图片字段与文字上下文组合，具体模型对图片数量的限制以服务响应为准。
- HF 专用目标检测及平台专用媒体任务逐条处理主资源，不接受额外字段拼接。所选资源决定检测坐标的归属；实体识别可明确文本跨度定位字段。
- 多字段顺序、组合格式和字段类型固定在任务中。所选字段缺失或类型无效时该条标为失败，不发送推理请求；0 和 false 是有效值。

## 运行边界

- GitHub Pages 是静态页面，直接请求 Hugging Face 官方接口。Token 只保存在当前页面 JavaScript 内存中，不进入 localStorage、sessionStorage、任务或导出文件。
- 预标注方案保存在浏览器 localStorage；连接、任务和结果保存在页面会话中，刷新会重置；请在刷新前导出需要保留的结果。
- HF 身份验证与推理权限验证分开：保存连接确认账户身份，模型权限、额度和区域限制由实际试运行检查。
- Hub revision 仅记录选择时的仓库状态，托管服务实际运行版本以服务商返回信息为准。
- 平台服务预标注、其他集成、质量扫描和向量等流程使用示例数据并标明模拟执行；HF 路径直接请求真实服务，不回退到模拟结果。
- 本次验证包括真实模型信息读取、无效 Token 的真实 401 响应，以及明确标记的接口契约测试。没有使用有效账户额度完成成功推理验收，需要使用者自行输入 Token 试跑。
- 2026-11-16 增量验证覆盖两种来源、平台已登记服务、本体/映射、组合输入的实际请求、图文附件、任务导出、异常策略、停止、额度不足和移动端布局。推理成功路径使用明确标记的契约响应，未验证生产平台模型服务。

## 在线模型列表与费用（2026-11-13 核查）

“模型预标注 → 浏览模型”读取 HF 当前在线服务，支持模型名搜索、服务商筛选、输出单价排序及仅显示 HF 标记免费的服务。

- 聊天及图文模型目录：https://router.huggingface.co/v1/models 。模型与服务商的价格单位为 USD / 百万 Tokens；仅 is_free=true 的服务被视为临时免费。缺失价格不等于免费。
- 目标检测目录使用 HF Hub 在线推理筛选；当前适配 hf-inference 的 object-detection 协议，至多读取 100 个候选。按计算时长计费，目录未提供具体单价。
- 读取公开列表不需要 Token，不发起推理请求。2026-11-13 实测：2 个目标检测模型、132 个聊天模型，其中 52 个支持图片输入；未发现明确标记免费的服务。
- 当前官方定价：免费账户没有自动赠送的月度推理额度；PRO 每月包含 $2 计算额度，Team / Enterprise 为每席位 $2。免费账户需购买额度，或使用服务商实际提供的临时优惠。
- 官方规则：https://huggingface.co/docs/inference-providers/en/pricing ；模型目录及价格字段说明：https://huggingface.co/docs/inference-providers/en/hub-api 。实际可用性、价格与优惠可能变化，请按最新接口和账户账单确认。
