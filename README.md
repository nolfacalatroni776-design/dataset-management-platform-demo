# 数据集管理平台交互 Demo

设计评审与交互体验用示例，包含数据集管理、数据浏览、语义画布、预标注、本体管理、难例挖掘、导入和存储管理。

设计说明：默认开启右上角“设计说明”。将鼠标停在字段、指标、按钮、表头或配置项上，可查看含义、信息来源、统计范围、点击结果和必要的使用条件；支持键盘聚焦，Esc 收起。弹窗内的说明先于弹窗收起，鼠标可移入浮层继续阅读。关闭开关可体验原交互和原有提示。本次仅更新 Demo，PRD 保持原样。

最新修订：2026-11-04。视图下拉底部提供“＋ 新建视图”，保存当前版本、子集与划分、已应用查询、排序、表格 / 画廊、预览字段和分页设置；创建后自动选中，管理中可定向更新和确认删除，同子集最多 5 个视图。画廊按钮悬停或键盘聚焦显示交互说明，每卡对应完整数据，可切换媒体、文本、JSON 等预览字段；列表展示首项及总数，预览与勾选分开，查找相似使用当前预览字段。切换表格 / 画廊保留查询、排序、分页和已选数据。搜索框提供关键词、语义、以媒体。查找相似直接从数据编号、字段单元格或媒体卡片发起，原查询区展示“相似于”条件；字段入口使用对应单字段索引，编号入口使用配置的字段组合并展示参与字段。Top K、方向、最低相似度与排除参考选项即时更新原列表。缺少索引时保留参考，预填字段及兼容模型构建索引，采用后继续查询。以媒体支持直接粘贴、预览与替换图片。保存视图保留参考 ID、字段、索引和参数。数据质量、重复检测、数据聚类以平铺操作打开，工具栏移除独立构建向量和哈希入口。聚类与语义近重复在配置字段和模型后自动匹配兼容向量，提交一次补齐缺口并分析；精确内容只复用或生成字段原值 / 媒体内容指纹，无需向量。准备区域显示复用、待处理和输入异常数量，结果保存补充、失败与跳过计数，重试保留成功项。相似查询缺索引时从当前条件构建，生成与分析任务从运行记录查看。语义画布独立生成二维投影。版本支持创建、发布和下拉切换；已移除版本对比。概览最近 3 条和完整操作记录共用日志，范围选择、字段排序及分布即时筛选继续保留。

导入流程：对象存储可浏览授权路径，勾选具体文件或选择整个文件夹（含子目录），准备后固定文件清单；Hugging Face 默认按固定 revision、config、来源 split 读取，也可选择仓库文件。本地记录支持多份 CSV、JSONL、JSON，媒体支持图片、音频、视频、文档、点云等混合导入，每个文件生成一条数据，按媒体类型匹配字段。成组图文由记录字段与媒体地址明确关联，视频保留整段。来源准备显示进度并可取消；自动检查只列格式、字段类型和文件可用性等问题，支持排除和恢复，无需手动复检或再次勾选确认。提交后展示排队、上传 / 读取、解析、保存进度，离开页面后任务在当前浏览器会话中继续；失败项在原任务重试，成功数据不重复写入。字段和入口继续提供设计说明 tooltip。

示例使用模拟数据，模型调用、向量、远程读取、文件上传与后台任务在浏览器内模拟。本地记录与媒体可实际选择和读取，单个记录文件本机解析上限 20 MB，Web 批次交互上限 20 GB；刷新恢复初始示例。打开页面即可体验，右上角“页面定位”可跳转交互场景，“重置演示”恢复初始示例。
