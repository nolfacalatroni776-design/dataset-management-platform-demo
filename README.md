# 数据集管理平台交互 Demo

设计评审与交互体验用示例，包含数据集管理、数据浏览、语义画布、预标注、本体管理、难例挖掘、导入、存储管理和外部工具集成。

设计说明：默认开启右上角“设计说明”。将鼠标停在字段、指标、按钮、表头或配置项上，可查看含义、信息来源、统计范围、点击结果和必要的使用条件；支持键盘聚焦，Esc 收起。弹窗内的说明先于弹窗收起，鼠标可移入浮层继续阅读。关闭开关可体验原交互和原有提示。

2026-11-09 修订：分享面板保留复制链接与公开页预览，已移除二维码展示和保存。数据集的“更多”只保留转移负责人、存储设置和删除数据集。视图下拉底部提供“＋ 新建视图”，保存当前版本、子集与划分、已应用查询、排序、表格 / 画廊、预览字段和分页设置；创建后自动选中，管理中可定向更新和确认删除，同子集最多 5 个视图。画廊按钮悬停或键盘聚焦显示交互说明，每卡对应完整数据，可切换媒体、文本、JSON 等预览字段；列表展示首项及总数，预览与勾选分开，查找相似使用当前预览字段。切换表格 / 画廊保留查询、排序、分页和已选数据。搜索框提供关键词、语义、以媒体。查找相似直接从数据编号、字段单元格或媒体卡片发起，原查询区展示“相似于”条件；字段入口使用对应单字段索引，编号入口使用配置的字段组合并展示参与字段。Top K、方向、最低相似度与排除参考选项即时更新原列表。缺少索引时保留参考，预填字段及兼容模型构建索引，采用后继续查询。以媒体支持直接粘贴、预览与替换图片。保存视图保留参考 ID、字段、索引和参数。数据质量、重复检测、数据聚类以平铺操作打开，工具栏移除独立构建向量和哈希入口。聚类与语义近重复在配置字段和模型后自动匹配兼容向量，提交一次补齐缺口并分析；精确内容只复用或生成字段原值 / 媒体内容指纹，无需向量。准备区域显示复用、待处理和输入异常数量，结果保存补充、失败与跳过计数，重试保留成功项。相似查询缺索引时从当前条件构建，生成与分析任务从运行记录查看。数据聚类统一从数据浏览发起，用于自动分组和挑选代表样本，无需先构建画布。语义画布独立生成二维投影，用于看分布和框选数据，不再提供聚类操作入口；已有匹配结果时，点位着色才显示“已有聚类分组”和“已有独特性分数”。版本支持创建、发布和下拉切换；已移除版本对比。概览最近 3 条和完整操作记录共用日志，范围选择、字段排序及分布即时筛选继续保留。

本体管理：按 Labelbox 的核心模型组织，创建时选择名称和数据类型，内容分为标注对象（Objects）、分类问题（Classifications）和对象关系（Relationships）。对象配置名称、工具、颜色和属性，属性使用单选、多选或自由文本问题；分类问题面向整个输入，答案支持排序、必答、搜索及命中答案后显示的后续问题；关系连接本体内的起点和终点对象。定义分组内可排序、归档，从同数据类型的已发布本体复制到草稿后独立编辑，复制关系自动带入依赖对象并重连端点。预标注先选本体，再选发布版本，可组合多个兼容本体；同一本体可供分类、检测等兼容任务复用，每个任务只使用适用的标注定义。任务提交时固定版本与定义快照，发布新版本不会改变历史任务。管理本体后返回未提交任务，保留原输入和范围，并选中新发布的兼容版本。生成类任务按输出格式和要求配置。各类定义的名称、用途和使用条件均通过 tooltip 说明。

运行记录：保留处理记录、导入记录、导出记录、外部调用四个页签，移除数据版本页签。处理类型完整列出模型预标注、难例挖掘、向量索引构建、哈希指纹构建、语义画布构建、二维投影、数据质量扫描、重复检测、数据聚类、子集复制和子集合并；支持类型、状态、名称 / ID 筛选及详情跳转。每条记录保存执行时的版本、子集和划分，展示本数据集的全部历史。外部调用按请求记录 API / SDK 查询、单条读取、媒体读取、分享访问和导出文件下载，展示调用时间、调用方和身份、读取范围、响应结果、返回条数 / 资源数 / 文件数及大小；详情包含请求 ID、接口、读取字段、参数、耗时、来源 IP 和失败原因。导出记录保存数据包生成任务，下载记为外部调用。数据浏览的 API 入口可模拟一次当前范围读取，返回前 100 条并生成同编号的调用记录；响应前 2 条可展开查看。

托管存储：创建数据集直接选择存储桶，下拉列表按“存储桶、所属区域、已用容量 / 配额”展示，默认预选可用的默认桶；配额已满或停用的桶展示状态并禁用。选定后回显桶名、区域和容量，区域由所选桶确定。平台按固定数据集 ID 自动分配目录，改名后目录保持不变。客户自有存储保留目标连接和路径。存储管理支持区域和状态筛选，新建桶写入共享配置并可在创建数据集时选择。概览和存储设置展示实际桶、区域与自动目录；存储配置在创建数据集时确定，创建后固定。创建时可暂不导入，也可直接导入首批文件。区域隔离在本 Demo 中为交互模拟，真实的数据驻留还需后端统一约束计算、索引、日志和备份等位置。

导入流程：进入对象存储或 Hugging Face 仓库文件来源后自动加载文件清单；勾选文件或选择整个文件夹（含子目录）后自动读取，修改范围自动更新，完成后固定文件清单。Hugging Face 的固定 revision、config、来源 split 修改后同样自动更新。本地支持 CSV、JSONL、JSON，也支持直接选择图片、音频、视频、文档、点云，可多选同类型文件、选择文件夹或拖入；选好即自动识别并读取。直接上传媒体时每批限同一种媒体类型，一个文件生成一条独立数据；不同媒体类型以及记录文件与媒体文件需要分批选择。混选时提示并禁用下一步，可直接保留其中一种类型后自动读取。确认页统一选择本批的媒体保存字段，只列类型相同的字段，并逐条展示每个文件对应的数据。文件名、路径和大小保存在导入来源记录中。成组图文由记录文件中的字段与媒体地址明确关联，视频保留整段。读取显示进度并可取消，取消后保持停止，可调整选择或重新读取；读取完成后才可到下一步。文件工具栏按钮、下拉框和连接操作统一高度并对齐。自动检查只列格式、字段类型和文件可用性等问题，支持排除和恢复，无需手动复检或再次勾选确认。提交后展示排队、上传 / 读取、解析、保存进度，离开页面后任务在当前浏览器会话中继续；失败项在原任务重试，成功数据不重复写入。字段和入口继续提供设计说明 tooltip。

示例使用模拟数据，模型调用、向量、远程读取、文件上传与后台任务在浏览器内模拟。本地记录与媒体可实际选择和读取，单个记录文件本机解析上限 20 MB，Web 批次交互上限 20 GB；刷新恢复初始示例。打开页面即可体验，右上角“页面定位”可跳转交互场景，“重置演示”恢复初始示例。

难例挖掘：原四步流程增加“按预测不确定性筛选（无需真值）”。单标签分类可选预测熵、前两类接近程度和低置信度；多标签分类可选预测熵和标签边界接近程度。分类输入可为文本、图片、音频、视频或 JSON，按模型输出结构判断是否兼容。熵与类别接近程度要求完整类别概率或 logits，分类问题、类别与分值必须一一对应；已有结果可定位 JSON 路径并确认分布完整，单标签低置信度只需预测类别及其置信度。检查列出缺失、异常和无法计算原因，可执行为零时阻止提交。结果统一为 0–1，高分优先复核；分布区间点击即时筛选，阈值与排序读取已保存指标，加入选择使用全部命中数据。单条展示实际分布、前两类概率、来源模型及计算含义，无参考区。检测 / 实例分割保留对象置信度方式，空预测单列；转写、语义分割和开放生成采用各自评价方式。示例“分类不确定性检查”可直接体验。模型概率 / logits 由本地示例生成，熵、间隔、边界及置信度转换按公式实际计算，结果用于安排复核顺序。此次同步了难例挖掘对应 PRD 的功能、配置、结果、异常及交互截图。

数据集存储设置：创建后只读查看保存方式和位置。平台托管展示区域、桶和平台自动分配的目录；客户自有存储展示连接和目标路径。弹窗仅提供“关闭”，不提供修改、保存或历史策略区域。创建数据集时仍可选择存储方式、存储桶或客户连接与路径。

外部工具集成（2026-11-09）：工作空间新增集成管理，统一维护数据来源、模型服务、向量检索连接，可筛选、验证、编辑、停用和恢复授权。导入的本地文件、对象存储、Hugging Face、Lance / LanceDB 为同级来源。Lance 来源按表和保留版本自动读取，文本、图片引用和 JSON 字段按原粒度进入字段确认；平台生成身份，来源 ID 和版本保留。Hugging Face 支持公开仓库或已授权连接，固定仓库 revision、config 和来源 split；授权范围外仓库阻止继续。预标注在原模型配置中选择适用的执行服务，任务固定连接修订和实际模型版本，分类继续引用本体，生成沿用输出要求。聚类、语义近重复、检索索引和画布构建可选检索服务，复用兼容向量；旧索引保留原后端。训练 / 评测使用从 API 或导出进入，固定已发布版本的完整身份清单，下载 HTTP / PyTorch 读取配置与示例；分页读取结果就地显示，调用写入原运行记录。外部调用可区分平台调用外部与外部读取平台。历史任务保留原配置，连接停用后阻止新执行；更新授权后可继续。对象存储仍在存储管理维护。外部人工标注为后续方案，一期未增加执行入口；版本对比与 Agent 对话继续不提供。

本轮为完整交互原型，真实连接器、模型调用、凭证托管、远程索引和训练 API 由后端实现；不与第三方真实账号建立连接。对应飞书 PRD 按同一交互规则维护。

本仓库通过 GitHub Pages 发布单文件交互 Demo。

### 2026-11-11 数据列表筛选

字段选择器支持搜索和按来源分组；枚举值支持搜索多选并显示数据条数。数值、媒体属性展示分布与单位；已登记 JSON 路径按类型筛选。预标注结果按任务选择处理状态、输出文本，或在同一对象内组合类别、置信度和数量。支持一层条件组、命中预览、条件摘要移除和撤销；保存视图带入完整查询配置。

### 2026-11-13 数据质量扫描配置

扫描前按字段选择检测项，可直接使用默认配置。检测项展开后展示计算方式、适用参数和可选判定条件：文本可忽略空白字符，音频可配置静音门限、最短静音段和削波幅度，视频可配置抽帧间隔、帧数上限和黑帧门限。固定算法和元信息指标只展示计算口径。每字段配置独立保存；计算参数影响对应指标，判定阈值直接使用已有指标。补扫复用兼容结果，未检测项可配置后补算。运行记录保存实际配置、复用数量和本次计算数量。质量结果页移除手动“待复核 / 已复核”下拉及“加入当前结果全部数据”，保留分布即时筛选、阈值预览、逐条选择和报告导出。
