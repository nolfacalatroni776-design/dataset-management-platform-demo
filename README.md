# 数据集管理平台 Demo

在线地址：https://nolfacalatroni776-design.github.io/dataset-management-platform-demo/

2026-11-13 更新：在现有数据列表和集成管理中增加 Hugging Face Inference Providers 真实预标注调用。

## 使用

1. 在“集成管理 → 连接 HF 推理服务”配置自己的 HF Access Token；也可在“模型预标注”窗口中直接配置。
2. Token 需要 Make calls to Inference Providers 权限、可用推理额度，以及所选模型需要的授权。
3. 打开数据集的数据浏览，选择同一子集的数据，点击“模型预标注”。
4. 选择输入字段、任务、模型和在线服务商，确认字段内容可发送给 HF 与所选服务商。
5. 先试运行 1 条，再执行剩余数据；查看检测框、文本、原始响应、耗时及任务统计，导出 JSON 结果。

支持图片目标检测（hf-inference）、图像描述、文本摘要/自定义指令、翻译、文本分类和 JSON 信息抽取；模型与服务商按 HF 实时返回的可用性检查。每批最多 50 条，顺序调用；失败项手动重试。401/402/403/429 会停止后续调用。

道路集原有样本是 demo SVG 插图；调用前转换为实际 PNG 内容。可在窗口中上传本地图片用于本次任务，原始数据保持不变。

## 运行边界

- GitHub Pages 是静态页面，直接请求 Hugging Face 官方接口。Token 只保存在当前页面 JavaScript 内存中，不进入 localStorage、sessionStorage、任务或导出文件。
- 连接、任务和结果保存在页面会话中，刷新会重置；请在刷新前导出需要保留的结果。
- HF 身份验证与推理权限验证分开：保存连接确认账户身份，模型权限、额度和区域限制由实际试运行检查。
- Hub revision 仅记录选择时的仓库状态，托管服务实际运行版本以服务商返回信息为准。
- 原有其他集成、质量扫描、向量等流程继续使用示例数据；“原模拟流程”有明确入口。HF 真实路径不回退到模拟结果。
- 本次验证包括真实模型信息读取、无效 Token 的真实 401 响应，以及明确标记的接口契约测试。没有使用有效账户额度完成成功推理验收，需要使用者自行输入 Token 试跑。

## 在线模型列表与费用（2026-11-13 核查）

“模型预标注 → 浏览模型”读取 HF 当前在线服务，支持模型名搜索、服务商筛选、输出单价排序及仅显示 HF 标记免费的服务。

- 聊天及图文模型目录：https://router.huggingface.co/v1/models 。模型与服务商的价格单位为 USD / 百万 Tokens；仅 is_free=true 的服务被视为临时免费。缺失价格不等于免费。
- 目标检测目录使用 HF Hub 在线推理筛选；当前适配 hf-inference 的 object-detection 协议，至多读取 100 个候选。按计算时长计费，目录未提供具体单价。
- 读取公开列表不需要 Token，不发起推理请求。2026-11-13 实测：2 个目标检测模型、132 个聊天模型，其中 52 个支持图片输入；未发现明确标记免费的服务。
- 当前官方定价：免费账户没有自动赠送的月度推理额度；PRO 每月包含 $2 计算额度，Team / Enterprise 为每席位 $2。免费账户需购买额度，或使用服务商实际提供的临时优惠。
- 官方规则：https://huggingface.co/docs/inference-providers/en/pricing ；模型目录及价格字段说明：https://huggingface.co/docs/inference-providers/en/hub-api 。实际可用性、价格与优惠可能变化，请按最新接口和账户账单确认。
