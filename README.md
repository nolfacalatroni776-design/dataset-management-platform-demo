# 数据集管理平台交互 Demo

设计评审与交互体验用示例，包含数据集管理、数据浏览、语义画布、预标注、本体管理、版本对比、难例挖掘、导入和存储管理。

最新修订：2026-11-03。概览的操作记录显示最近 3 条，标题 tooltip 说明字段与时间口径；“查看完整操作记录”和“更多 → 操作记录”进入同一完整列表，支持版本、类型、操作者、结果、日期与关键词筛选，展开查看前后值及关联任务。草稿相关操作通过版本筛选查看。子集与划分直接切换、版本下拉、字段排序、分布即时筛选及前期修订继续保留。

示例使用模拟数据，模型调用、向量与异步任务在浏览器内模拟。打开页面即可体验，使用右上角“页面定位”跳转到各交互场景；“重置演示”恢复初始示例。

本仓库通过 GitHub Pages 发布单文件交互 Demo。
